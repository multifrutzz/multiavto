# Техническое задание: «multiavto»

Вариант № 11 - магазин автомобилей.

Сайт предназначен для просмотра и подбора автомобилей по бюджету, году выпуска и пробегу. Посетитель может открыть подробную информацию о машине и сравнить характеристики нескольких автомобилей.

## Страницы сайта

1. Главная - описание магазина и подборка из 5-6 автомобилей с фотографиями и ссылками.
2. Каталог - не менее 12 автомобилей, элементы фильтрации и сортировки.
3. Страница автомобиля - фотография, описание, цена и характеристики.
4. Сравнение - таблица характеристик выбранных автомобилей.
5. Контакты - адрес, телефон, режим работы, слоган и форма обратной связи.


## Возможности второй практической работы

Форма каталога должна проверять введённые значения и фильтровать автомобили по цене, году выпуска и пробегу.

Сортировка должна менять порядок найденных автомобилей без перезагрузки страницы. Должен быть доступен сброс фильтров.

Форма обратной связи должна проверять имя, электронную почту и сообщение. Ошибки должны отображаться рядом с полями, успешная проверка — подтверждаться сообщением на странице. Данные формы не отправляются и не сохраняются.

Каталог должен асинхронно получать курс доллара из API cbr-xml-daily.ru через fetch и показывать справочный пересчёт цен в доллары.

Необходимо предусмотреть сообщение о загрузке, обработку ошибки запроса и кнопку повторной загрузки. При недоступном источнике фильтрация, сортировка и рублёвые цены должны оставаться доступными.
